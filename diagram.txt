# ZES.codes Free-Tier Pipeline — Text Schematic

Design reference for the planned free-tier flow. Only the orchestration and the
deploy script exist in code today; the QC Council and R2 upload stages are not
implemented yet (see README → Current Status).

```text
[ User ]
   │
   │ 1. Inputs Title & Niche
   ▼
[ app.zes.codes (Frontend UI) ]
   │
   │ 2. Sends Request
   ▼
[ zes-agent-hub (Orchestrator) ]
   │
   │ 3. Request Image
   ▼
[ Pollinations Image API ] ◄─────────────────────────┐
   │                                                 │
   │ 4. Returns Raw Image                            │
   ▼                                                 │
[ QC Council (planned) ]                             │
   │                                                 │
   ├─► 5a. NVIDIA Super VL ──┐                       │
   │                         ├─► 6. Consensus JSON   │
   └─► 5b. Nemotron Omni ────┘                       │
   │                                                 │
   │ 7. Verdict (Pass/Fail)                          │
   ▼                                                 │
[ Hub Decision ]                                     │
   │                                                 │
   ├─► IF FAIL (max 3 retries) ──► New Seed ─────────┘
   │
   └─► IF PASS
         │
         │ 8. Upload Image (planned: Cloudflare R2)
         ▼
   [ Cloudflare R2 Storage ]
         │
         │ 9. Returns Public Image URL
         ▼
   [ zes-agent-hub ]
         │
         │ 10. Request Copy
         ▼
   [ Pollinations Text API ]
         │
         │ 11. Returns Hero Copy
         ▼
   [ zes-agent-hub ]
         │
         │ 12. Injects Title, Niche, Copy and Image into index.html
         ▼
   [ ZES HTML Template ]
         │
         │ 13. Deploy Final HTML
         ▼
   [ Cloudflare Workers (wrangler deploy) ]
         │
         │ 14. Returns Live URL
         ▼
   [ app.zes.codes (displays the live URL) ]
```
